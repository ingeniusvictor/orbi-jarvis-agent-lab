# LUMIA VOICE-01M — AMI independent reference benchmark

Fecha: 12-11-2026. Scope: isolated lab only.

## Why this test exists

VOICE-01J/K/L gave evidence of potential overfragmentation of A/C/D in ONE public WAV. No independently annotated reference exists for that clip. VOICE-01M uses a NEW public AMI meeting with published human annotation, without tuning clustering thresholds first.

## Trusted public sources

- Meeting: AMI ES2002a, Mix-Headset WAV, 16 kHz mono.
- Official AMI audio: https://groups.inf.ed.ac.uk/ami/AMICorpusMirror/amicorpus/ES2002a/audio/ES2002a.Mix-Headset.wav
- Published reference: https://github.com/pyannote/AMI-diarization-setup/blob/main/only_words/rttms/train/ES2002a.rttm
- Documentation: https://github.com/pyannote/AMI-diarization-setup
- AMI download and license: https://groups.inf.ed.ac.uk/ami/download/ (audio/manual annotations CC BY 4.0).

Frozen clip 60.0–160.0 s (100 seconds). Prepared reference starts at 0 seconds, is cropped and relabeled p0/p1/p2/p3 locally. Reference was manually annotated before this lab, not generated by CAM++.

## Implemented

Python: voice01m_ami_benchmark.py

- --doctor: never downloads, imports models or writes files.
- --prepare --consent: explicit HTTPS download of a publicly available meeting and separate reference. Keeps only a clipped local WAV, anonymous RTTM and manifest containing SHA256 hashes. Original full meeting audio is never saved on disk by the script; the clip and anonymized reference are retained under LOCALAPPDATA/ORBI/LUMIA-VOICE-LAB/benchmarks/voice01m_ami. Does NOT affect LUMIA live.
- --run --consent: offline CAM++ clustering, threshold fixed at 0.5, automatic speaker count; checks clip and annotation SHA256.
- --run --compare --consent: also tests ERes2Net against the SAME manually labeled clip. No other network calls, installs or audio persistence.
- The evaluated outputs are aggregate speaker count, timing and time-integrated MISS, false alarm, speaker confusion, overlap and error ratios. It never prints real speaker labels or audio transcripts.

Scoring label: time_integrated_der_like_no_collar_not_official_DER. Unlike the earlier nonoverlap 10-ms proxy, this integrates exact start/end intervals and includes overlapping voices, counting two simultaneously active reference speakers as two speaker-seconds. It is NOT the official AMI/md-eval/pyannote DER: no collar, no separate UEM, and the published only_words reference excludes some vocal sounds. Do not directly compare its percentage to published DER numbers.

The full public meeting may be tens of MB: the explicit prepare step requires internet, while the evaluation itself is offline. License/attribution applies to local copies. No private speech and no user identity recognition.

## ASUS PowerShell

The isolated worktree may be detached HEAD. Do not use git branch --show-current with Trim(). Never hard reset or change main.

~~~powershell
$lab = Join-Path $env:USERPROFILE "LUMIA-VOICE-LAB"
$data = Join-Path $env:LOCALAPPDATA "ORBI\LUMIA-VOICE-LAB"
$branch = "feature/lumia-voice01-offline-diarization-lab-20261109"
Push-Location $lab
try {
    $top = git rev-parse --show-toplevel
    if ($LASTEXITCODE -ne 0 -or [string]::IsNullOrWhiteSpace($top)) {
        throw "No es un repositorio Git valido."
    }
    if ((Resolve-Path $top).Path -ine (Resolve-Path $lab).Path) {
        throw "Raiz Git inesperada."
    }
    $changes = @(git status --porcelain)
    if ($LASTEXITCODE -ne 0 -or $changes.Count -gt 0) {
        throw "Hay cambios locales: revisar antes de avanzar."
    }
    git fetch origin "refs/heads/$branch"
    if ($LASTEXITCODE -ne 0) { throw "Git fetch fallo." }
    git merge-base --is-ancestor HEAD FETCH_HEAD
    if ($LASTEXITCODE -ne 0) { throw "No se puede hacer fast-forward." }
    git merge --ff-only FETCH_HEAD
    if ($LASTEXITCODE -ne 0) { throw "Git merge fallo." }

    $py = Join-Path $data ".venv\Scripts\python.exe"
    $bench = Join-Path $lab "labs\voice-01\voice01m_ami_benchmark.py"
    & $py -B $bench --doctor
    if ($LASTEXITCODE -ne 0) { throw "Doctor fallo." }
    # Consent is explicit: this prepares the public CC BY 4.0 benchmark.
    & $py -B $bench --prepare --consent
    if ($LASTEXITCODE -ne 0) { throw "Preparacion fallo." }
    & $py -B $bench --run --compare --consent
    if ($LASTEXITCODE -ne 0) { throw "Inferencia fallo." }
}
finally {
    Pop-Location
}
~~~

If already prepared, --prepare deliberately errors with LOCAL_BENCHMARK_ALREADY_EXISTS to prevent overwrite: re-run --run --compare --consent instead. Share JSON output only, not the WAV or RTTM.
