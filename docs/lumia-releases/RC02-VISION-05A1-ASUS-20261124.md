## Funcionalidad
- Desde el perfil habitual **Escritorio sentado**, puede reconocer izquierdo, derecho y ambos brazos levantados **cuando son visibles**, tal como se comprobó en NEXT.
- No clasifica automáticamente si la persona está sentada; el perfil es **contexto de uso**, no inferencia visual.
- Brazos abajo con muñecas/codos fuera de la webcam: «indeterminado» con causa de recorte, **no inferir «abajo»**.
- Botón **Activar postura · CPU** aparece después de **Activar visión**. Es un switch separado: el visor, el detector de rostros y la cámara no se activan automáticamente.
- Pose Lite CPU realiza una inferencia aprox. cada 2,5 s, tamaño máximo 640×360, exige dos lecturas iguales. No envía poses a Qwen ni almacena fotogramas.
- No se ha integrado con las cámaras eufy ni con Qwen 4B/CPU 0.8B. No hay promesa de reconocimiento de piernas/cuerpo completo.

## Reutilizar el mismo checkout de QA ASUS (NO ejecutar con RC01 abierta)

```powershell
$qa = Join-Path $env:USERPROFILE 'LUMIA-RC01-QA'
$original = Join-Path $env:USERPROFILE 'LUMIA-ASUS'
Set-Location $qa
if (git status --porcelain) { throw 'RC01 QA tiene cambios locales; no actualizar' }
if ((git -C $original rev-parse HEAD).Trim() -ne '1580a5182eba540893e35e37065be77da4ed014c') {
  throw 'La ASUS original ya no coincide con la línea protegida'
}
git fetch origin
if ($LASTEXITCODE -ne 0) { throw 'Falló fetch' }
git switch --track origin/release-candidate/lumia-vi05a1-asus-20261124
if ($LASTEXITCODE -ne 0) { throw 'Falló cambio a RC02' }
node scripts/lumia-private-avatar-assets-rc01.mjs --require
if ($LASTEXITCODE -ne 0) { throw 'Los 18 recursos no están presentes' }
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\instalar-modelo-pose-rc02.ps1
if ($LASTEXITCODE -ne 0) { throw 'No se validó Pose Lite' }
.\INICIAR_LUMIA_VISION_RC02_ASUS.cmd
```
